

# To Do List

## Description
This is the frontend for the todolist app, which allows users to create , read, update, delete tasks with additional security , such as being able to create an account for security <br/>

Next.js over React because it’s a full framework, not just a UI library: it gives you routing, server-side rendering, data fetching, API endpoints, and performance optimizations out of the box, which means better SEO, faster initial loads, and less time wiring up tooling. React alone is great for building interfaces, but you must assemble and maintain your own router, build setup, SSR solution, and backend integration. In short, React builds components; <br/>

<strong> Next.js ships production-ready apps faster, with stronger defaults and scalability baked in. </strong>

## Tech Stack
- Next Js (React)

### Libraries

- React
- React Boostrap
- MUI
- React Multi-Carousel
- Redux

## Features
 
 - Create, Read, Update, Delete Task
 - Search for Task
 - Login/Register for account (Security)
 - Pagination

 ## Security
 - JWT Token
